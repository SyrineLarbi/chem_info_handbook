AI cheminformatics · Volume 10 of 17 · phase 2

Deep learning and graph networks. Learning the representation instead of choosing it.

A fingerprint is a fixed recipe someone wrote in 2010. A graph neural network learns the recipe from your data. That is the whole idea — and this volume covers how it works, when it genuinely beats a random forest, and why the literature's answer to that question is more optimistic than the evidence.

Part I

The idea

Lesson 01

Learned versus fixed features

  THE FIXED PIPELINE (Volumes 05 and 08)

    molecule --> [Morgan fingerprint] --> [random forest] --> prediction
                  ^ fixed recipe            ^ learned
                  decided in advance,
                  identical for every task


  THE LEARNED PIPELINE (this volume)

    molecule --> [graph neural network] ----------------> prediction
                  ^ the representation AND the model are
                    learned together, from THIS task's data

  ⭐ THE BET: that a representation tuned to your endpoint beats a
     general-purpose one. Whether that bet pays depends almost
     entirely on HOW MUCH DATA YOU HAVE — because a learned
     representation has to be learned from something.
Lesson 02

Message passing — the core algorithm

Worked example · the algorithm, on a small molecule 
START: every atom gets a feature vector describing ITSELF
       element, degree, charge, aromatic?, ring?, H count ...

       h(C1) = [...]   h(C2) = [...]   h(O3) = [...]

LAYER 1 — each atom collects MESSAGES from its neighbours
       m(C2) = MESSAGE( h(C1), bond type ) + MESSAGE( h(O3), bond type )
       h'(C2) = UPDATE( h(C2), m(C2) )

       ...where MESSAGE and UPDATE are small neural networks
          whose weights are LEARNED.

       Now every atom's vector encodes itself + its neighbours.

LAYER 2 — do it again, using the UPDATED vectors
       Now every atom's vector encodes its 2-bond neighbourhood,
       because its neighbours already knew about THEIR neighbours.

LAYER k — the receptive field is k bonds.

READOUT — combine all atom vectors into ONE vector for the molecule
       sum, mean, max, or a learned attention-weighted pool

       --> feed that to a normal neural network --> prediction

The one-sentence version for a chemist: "Each atom repeatedly updates its description by looking at its neighbours, so after three rounds every atom knows about its surroundings three bonds out — and we learn what parts of that neighbourhood matter, instead of deciding in advance."

Lesson 03

It is the Morgan algorithm, with learned functions

The connection that makes GNNs click

Put the two algorithms side by side:

MORGAN FINGERPRINT (Volume 05)          GRAPH NEURAL NETWORK
  start: atom identifier                  start: atom feature vector
  round: combine with neighbours'         layer: combine with neighbours'
         identifiers, then HASH                  vectors, then a LEARNED
                                                 NEURAL NETWORK
  collect: all identifiers -> bits        readout: pool all vectors
  radius r = how far it reaches           k layers = how far it reaches

⭐ SAME ALGORITHM. The difference is that Morgan uses a FIXED HASH
   and a GNN uses a LEARNED FUNCTION.

Three things follow immediately from that equivalence, and they explain most GNN behaviour:

  • A GNN inherits Morgan's locality. Three layers means three bonds. Long-range relationships are invisible to both, which is why atom-pair fingerprints and, later, attention mechanisms exist.
  • A GNN can only beat Morgan if the learned function beats the hash — and learning a function takes data. With 500 compounds there is not enough signal to learn anything better than a hash.
  • With enough data it should win, because the hash throws away information the learned function can keep.

Lesson 04

Featurising atoms and bonds

The standard starting features
PER ATOM
  element                  one-hot over C, N, O, S, F, Cl, Br, I, P, other
  degree                   0-5, one-hot
  formal charge            -2..+2
  chirality tag            one-hot
  number of hydrogens      0-4
  hybridisation            sp, sp2, sp3, ...
  aromatic                 boolean
  in a ring                boolean
                           -> a vector of ~30-130 numbers per atom

PER BOND
  bond type                single / double / triple / aromatic
  conjugated               boolean
  in a ring                boolean
  stereo                   one-hot

⭐ NOTE WHAT IS ABSENT: no molecular weight, no LogP, no global
   property. The network is expected to derive what it needs from
   local structure. In practice, CONCATENATING A FEW GLOBAL
   DESCRIPTORS ONTO THE READOUT VECTOR OFTEN HELPS -- especially
   for physical properties that genuinely are bulk properties.
Lesson 05

GCN, GAT, MPNN, D-MPNN

ArchitectureWhat distinguishes itNotes
GCN
graph convolutional		Averages neighbour vectors with a fixed normalisation.Simplest. Ignores bond features entirely, which for chemistry is a real loss — a single and a double bond are treated alike.
GAT
graph attention		Learns how much to weight each neighbour.More expressive; the attention weights are a bonus interpretability signal, though a weak one.
MPNN
message passing NN		The general framework — messages are functions of both atoms and the bond between them.The umbrella the others sit under. Uses bond features properly.
D-MPNN
directed, as in Chemprop		Messages travel along directed bonds rather than atoms.The strong practical default for molecular property prediction. The direction stops a message from immediately bouncing back to where it came from, which reduces a form of redundancy that hurts atom-centred message passing.
3D / equivariant
SchNet, DimeNet, EGNN		Use actual atomic coordinates, respecting rotation and translation.Necessary for quantum properties and protein–ligand work. Inherit the conformer problem from Volume 03.
Lesson 06

Readout — turning atoms into a molecule

ReadoutBehaviourWhen it is right
SumGrows with molecule sizeExtensive properties — things that genuinely scale with size, like total energy.
MeanSize-independentIntensive properties. The safer default for activity.
Max"Is any part of this molecule like X?"When one substructure dominates the property — toxicity alerts, for instance.
Attention poolingLearns which atoms matterBest performance and the most interpretable, at the cost of parameters and data.
A real decision, not a detail

Sum versus mean is the difference between a model that thinks bigger molecules are more active and one that does not. If your dataset happens to correlate size with activity — and many do, because chemists add mass while optimising — a sum readout will learn "bigger is better" and generalise badly to a new series. Prefer mean unless the property is genuinely extensive.

Lesson 07

Over-smoothing — why deeper is not better

The failure mode specific to graph networks

Each layer mixes each atom's vector with its neighbours'. Stack enough layers and every atom's vector converges towards the same thing — the network has averaged the molecule into mush and lost the local detail it was supposed to capture.

This is why molecular GNNs are shallow. Three to five message-passing layers is typical, and adding more usually makes performance worse rather than better. Given that drug-sized molecules are only 10–15 bonds across, three layers already reaches most of the molecule.

Residual connections and jumping-knowledge layers mitigate it, but the practical advice stands: if you are reaching for a tenth layer, the problem is not depth.

Part III

Using them honestly

Lesson 08

When they actually help

The honest benchmark position

On typical medicinal chemistry datasets of a few hundred to a few thousand compounds, a well-tuned random forest on Morgan fingerprints is competitive with — and often beats — a graph neural network. This result has been reproduced repeatedly, and it is not a fringe position.

Where the literature overstates it
  • Under-tuned baselines. The GNN gets a hyperparameter sweep; the random forest gets defaults.
  • Random splits. Deep models are better at memorising series, so a random split flatters them specifically.
  • Benchmark sets, not project data. MoleculeNet sets are large, clean and public. Your project data is small, messy and proprietary.
  • Publication bias. "Our GNN matched a random forest" is not a paper.
When to reach for one anyway
  • Large data — tens of thousands of compounds and up.
  • Multi-task — many related endpoints sharing one representation. This is where GNNs earn their place most clearly (Lesson 09).
  • Pretraining available — a model pretrained on millions of unlabelled molecules, then fine-tuned on your few hundred. Volume 13.
  • You need atom-level attribution — which colours a molecule directly, and is genuinely more useful to a chemist than fingerprint-bit importance.
  • 3D matters — quantum properties, binding poses. Fingerprints simply cannot express this.
Lesson 09

Multi-task learning — the clearest win

Worked example · why sharing helps 
THE SITUATION — a typical ADMET panel

  solubility        4,200 compounds measured
  permeability      2,800
  hERG              3,100
  CYP3A4            2,400
  microsomal        1,900
  YOUR TARGET         340   <-- the one you care about

SINGLE-TASK: train on 340 compounds. Almost certainly too few.

MULTI-TASK:  one shared GNN trunk, six output heads.
             The trunk learns molecular representation from
             ALL 14,740 measurements; the small head learns
             your specific endpoint from its 340.

⭐ THE SHARED TRUNK IS TRAINED ON 40x MORE DATA THAN YOUR TASK HAS.
   This is the single most reliable way a neural approach beats a
   random forest on small chemical data -- and it is unavailable
   to a per-task random forest by construction.

The caution: negative transfer is real. If one task is unrelated to the rest, it can degrade the shared representation. Check by comparing each task's multi-task performance against its own single-task baseline, and drop tasks that hurt.

Lesson 10

Uncertainty — because a prediction without one is not usable

MethodHowTrade-off
EnsembleTrain 5–10 models with different seeds; use the spread of their predictions.The most reliable, and the standard. Costs 5–10× the training time — which for these model sizes is usually acceptable.
MC dropoutLeave dropout active at prediction time and sample repeatedly.Cheap. Known to be less well calibrated than ensembles.
Evidential / mean-varianceThe network predicts its own variance.Single model, one pass. Calibration varies; check it before trusting it.
Conformal predictionWraps any model to produce intervals with a guaranteed coverage rate.Statistically principled and increasingly the preferred answer. Gives "90% of true values will fall in this interval", which is exactly what a chemist wants.
The link back to Volume 08

Uncertainty and applicability domain answer the same question by different routes. A high predicted variance and a low nearest-neighbour similarity usually flag the same compounds. Report both — they fail differently, and a compound flagged by both is one you should refuse to predict rather than merely caveat.

Lesson 11

Attribution — colouring the molecule

The most chemist-friendly output any model in this course produces: a picture of the molecule with atoms coloured by how much they contributed. Red for atoms pushing the prediction down, green for up.

Use it, and distrust it a little

Attribution methods disagree with each other, and they explain the model rather than the chemistry. A model that learned a spurious correlation will produce a confident, beautiful and wrong attribution map.

The right use is as a conversation starter. Show it to a chemist and ask "does this make sense?" If it highlights the group they already know matters, your model has probably learned something real. If it highlights a methyl on the far side of the molecule, you have found a problem — which is also valuable.

Lesson 13

Setting up a fair comparison

The protocol — do this before believing any claim, including your own
  □  SAME SPLIT for both models — scaffold or time, and the same
     random seed. Not "a scaffold split" each; THE SAME ONE.

  □  TUNE THE BASELINE TOO. Give the random forest the same
     hyperparameter search budget as the GNN. This single step
     closes most reported gaps.

  □  REPEAT over 5+ different splits and report mean and spread.
     A single split difference of 0.03 R2 is noise, and on small
     chemical datasets the spread across splits is often larger
     than the difference between methods.

  □  COMPARE TRAINING COST. If the GNN wins by 0.02 R2 and costs
     100x the compute and a week of your time, that is a finding
     about the project, not just about the models.

  □  CHECK PERFORMANCE ON THE HARD SUBSET — the compounds whose
     nearest training neighbour is distant. Averages hide the
     part you actually care about.

⭐ IF THE GNN STILL WINS AFTER ALL FIVE, IT REALLY WINS.
   Most of the time, on most project datasets, it will not —
   and knowing that saves you months you can spend on the data
   instead, where the gains actually are.

Try it · Your GNN gets R² 0.71; a random forest on ECFP4 gets 0.69 on the same scaffold split. Which do you ship?
Answer

The random forest — unless you can show the 0.02 is real, and you almost certainly cannot.

FIRST, IS THE DIFFERENCE EVEN THERE?
   Re-run both across several random seeds and report the
   spread. A 0.02 gap with a seed-to-seed spread of 0.04 is
   not a result, it is noise. This check takes an hour and
   settles most GNN-versus-baseline arguments.

THEN, THE COSTS THE METRIC DOES NOT SHOW
   · the RF trains in seconds on a laptop; the GNN needs a
     GPU and an environment someone must maintain
   · the RF gives feature importances a chemist can read
   · the RF has no epochs, no learning rate, no checkpoint
     to go stale
   · someone else must be able to retrain this in a year

⭐ SHIP THE GNN WHEN IT WINS BY A MARGIN THAT SURVIVES
   RESEEDING, or when it brings something the RF cannot —
   multi-task sharing, atom-level attribution, or a
   pretrained starting point.

And the thing to actually say: "the GNN is not better yet — here is the data size at which I would expect it to be." That answer is more impressive than the model.

Lesson 14

The architecture zoo, and which ones matter

There are dozens of published GNN architectures. Six are worth recognising, and the useful axis is not "newest" — it is what geometry the model can see.

ModelThe ideaSeesUse it when
GCN
2017		The simplest convolution over a graph2D onlyA teaching baseline. Its flaw: messages lose track of where they came from.
MPNN
2017		Edge-conditioned messages — bonds carry information2DThe general framework the others are variations on.
D-MPNN
2019		Directed message passing, so a message never flows back where it came from2DThe best 2D architecture, and what Chemprop implements. This is the sensible default.
AttentiveFP
2020		Attention-based readout instead of averaging every atom2DWhen the property is decided by one part of the molecule — pKa by the ionisable group, say — rather than by the whole thing.
SchNet
2017		Continuous-filter convolutions over interatomic distances3D distancesEnergies and forces.
DimeNet / SphereNet
2020 / 2022		Adds angles, then full spherical geometry3D anglesConformer-dependent properties, where distance alone genuinely is not enough.
The trap in the 3D column

A 3D architecture needs 3D coordinates, and for most drug-discovery datasets you do not have the bioactive conformer — you have a generated one (Volume 12, Lesson 11). So a geometric model is reasoning about a shape you guessed. That is why D-MPNN on 2D graphs remains competitive on ordinary property prediction, and why the 3D models earn their place mainly where the geometry is known or is itself the label, as in energies and forces.
