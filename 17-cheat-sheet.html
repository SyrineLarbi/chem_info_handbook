Snippet 01

Reading and writing molecules

Volume 03 · every pipeline starts here
from rdkit import Chem

# --- parse ---------------------------------------------------
mol = Chem.MolFromSmiles("CCO")
if mol is None:                    # ⭐ ALWAYS. Returns None on
    ...                            #    failure — it does not raise.

mol = Chem.MolFromSmarts("[OX2H]")         # a QUERY, not a molecule
mol = Chem.MolFromMolBlock(block)          # MOL / SDF text
mol = Chem.MolFromInchi("InChI=1S/C2H6O/...")

# --- write ---------------------------------------------------
Chem.MolToSmiles(mol)              # CANONICAL — the only form to
                                   # compare or store as a key
Chem.MolToSmiles(mol, isomericSmiles=False)   # drop stereo
Chem.MolToInchiKey(mol)            # 27 chars, the database key
Chem.MolToMolBlock(mol)

# --- files ---------------------------------------------------
supplier = Chem.SDMolSupplier("compounds.sdf")
for mol in supplier:               # ⭐ yields None for bad entries
    if mol is None:
        continue

with Chem.SDWriter("out.sdf") as w:
    w.write(mol)

# a CSV of SMILES is usually just pandas + a parse column
import pandas as pd
df = pd.read_csv("data.csv")
df["mol"] = df["smiles"].apply(Chem.MolFromSmiles)
bad = df[df["mol"].isna()]         # ⭐ LOG THESE. Never drop silently.

# --- properties on the molecule ------------------------------
mol.GetNumAtoms()                  # heavy atoms only, by default
mol.GetNumAtoms(onlyExplicit=False)
mol.GetNumHeavyAtoms()
mol.GetRingInfo().NumRings()
for atom in mol.GetAtoms():
    atom.GetSymbol(), atom.GetDegree(), atom.GetIsAromatic()
Snippet 02

Standardising a molecule

Volume 06 · the step that decides whether your dataset is real
from rdkit.Chem.MolStandardize import rdMolStandardize

# the usual order --------------------------------------------
mol = rdMolStandardize.Cleanup(mol)          # sanitise, fix valences
                                             # normalise functional groups

lfc = rdMolStandardize.LargestFragmentChooser()
mol = lfc.choose(mol)                        # ⭐ STRIP THE SALT.
                                             # "drug.HCl" -> "drug"

un  = rdMolStandardize.Uncharger()
mol = un.uncharge(mol)                       # neutralise where sensible

te  = rdMolStandardize.TautomerEnumerator()
mol = te.Canonicalize(mol)                   # ONE canonical tautomer
                                             # (slow — do it once, store it)

smiles = Chem.MolToSmiles(mol)               # now it is comparable

# ⭐ THE DEDUPLICATION KEY
#    canonical SMILES of the STANDARDISED molecule, or its
#    InChIKey. Never the raw input string — the same compound
#    arrives written five different ways.

# ⭐ AND THE RULE THAT MATTERS MORE THAN ANY SNIPPET
#    NEVER STANDARDISE IN PLACE. Keep the raw column, add a
#    standardised column, and log what each step changed.
#    A cleaning rule you cannot reverse is a decision you
#    cannot revisit.
Snippet 03

Descriptors

Volume 05 · the standard profile
from rdkit.Chem import Descriptors, Crippen
from rdkit.Chem import rdMolDescriptors as rdmd

Descriptors.MolWt(mol)             # molecular weight
Crippen.MolLogP(mol)               # CALCULATED logP (not measured)
rdmd.CalcTPSA(mol)                 # topological polar surface area
rdmd.CalcNumHBD(mol)               # H-bond donors
rdmd.CalcNumHBA(mol)               # H-bond acceptors
rdmd.CalcNumRotatableBonds(mol)    # flexibility
rdmd.CalcNumRings(mol)
rdmd.CalcNumAromaticRings(mol)
rdmd.CalcFractionCSP3(mol)         # "3D-ness"; higher is often better
Descriptors.NumRadicalElectrons(mol)

# everything at once (200+) ----------------------------------
from rdkit.Chem import Descriptors
names = [n for n, _ in Descriptors.descList]
calc  = Descriptors.CalcMolDescriptors(mol)      # dict, modern RDKit

# ⭐ WARNINGS
#  · MolLogP is a CALCULATION, and it disagrees with measured
#    logP by ~0.5-1 log unit routinely. Never present it as measured.
#  · many of the 200 are near-duplicates of each other — see the
#    multicollinearity note in Volume 05.
#  · a descriptor that is constant across YOUR set is useless,
#    however famous it is.
Snippet 04

Fingerprints and similarity

Volume 05 and 07 · the workhorse
from rdkit.Chem import rdFingerprintGenerator
from rdkit import DataStructs

# --- the modern generator API (preferred) --------------------
gen = rdFingerprintGenerator.GetMorganGenerator(radius=2, fpSize=2048)
fp  = gen.GetFingerprint(mol)

#   radius 2 == "ECFP4"   (⭐ the 4 is the DIAMETER, not the radius —
#   radius 3 == "ECFP6"    the single most common naming confusion)

# you will still see the older call everywhere:
#   from rdkit.Chem import AllChem
#   AllChem.GetMorganFingerprintAsBitVect(mol, 2, nBits=2048)

# other generators
rdFingerprintGenerator.GetRDKitFPGenerator()          # path-based
rdFingerprintGenerator.GetAtomPairGenerator()         # long-range
rdFingerprintGenerator.GetTopologicalTorsionGenerator()
from rdkit.Chem import MACCSkeys
MACCSkeys.GenMACCSKeys(mol)                           # 166 fixed keys

# --- similarity ----------------------------------------------
DataStructs.TanimotoSimilarity(fp1, fp2)              # the default
DataStructs.DiceSimilarity(fp1, fp2)
DataStructs.BulkTanimotoSimilarity(fp, [fp1, fp2, ...])   # ⭐ use this
                                                          # for one-vs-many

# --- as a numpy array for sklearn ----------------------------
import numpy as np
arr = np.zeros((0,), dtype=np.int8)
DataStructs.ConvertToNumpyArray(fp, arr)

# ⭐ THE NUMBER THAT IS NOT PORTABLE
#    "Tanimoto 0.85" means nothing without the fingerprint type
#    and size. 0.85 on MACCS is not 0.85 on ECFP4. Always state
#    which fingerprint produced it.
Snippet 05

Substructure and SMARTS

Volume 03 · asking structural questions
patt = Chem.MolFromSmarts("c1ccccc1")       # benzene ring
mol.HasSubstructMatch(patt)                 # True / False
mol.GetSubstructMatches(patt)               # tuples of atom indices

# SMARTS you will use constantly ------------------------------
"[OX2H]"              alcohol OH
"[CX3](=O)[OX2H1]"    carboxylic acid
"[NX3;H2,H1;!$(NC=O)]"  primary/secondary amine, NOT an amide
"[#6]"                any carbon (aliphatic or aromatic)
"c"                   aromatic carbon      "C"  aliphatic carbon
"[R]"                 any ring atom        "[!R]" not in a ring
"[$(...)]"            recursive SMARTS — "atom in this context"
"~"                   any bond             "@"  ring bond

# ⭐ SMILES vs SMARTS
#    SMILES describes ONE molecule.
#    SMARTS describes a PATTERN that matches many.
#    Every SMILES is valid SMARTS; the reverse is not true,
#    and using MolFromSmiles on a pattern silently gives you
#    the wrong thing rather than an error.

# reactions ---------------------------------------------------
from rdkit.Chem import AllChem
rxn = AllChem.ReactionFromSmarts("[C:1](=[O:2])[OH].[N:3]>>[C:1](=[O:2])[N:3]")
products = rxn.RunReactants((acid, amine))
#   the :1 :2 :3 are ATOM MAPS — they carry identity across the arrow
Snippet 06

Scaffolds and splitting

Volume 08 · the split decides whether your number is honest
from rdkit.Chem.Scaffolds import MurckoScaffold

scaffold = MurckoScaffold.MurckoScaffoldSmiles(mol=mol)
# strips all side chains, keeps ring systems + linkers

scaffold = MurckoScaffold.MurckoScaffoldSmiles(mol=mol,
                                               includeChirality=False)

# --- a scaffold split ----------------------------------------
from collections import defaultdict

groups = defaultdict(list)
for i, m in enumerate(mols):
    groups[MurckoScaffold.MurckoScaffoldSmiles(mol=m)].append(i)

# sort scaffold groups largest-first, fill train to ~80%,
# then the rest go to test. Whole scaffolds never split across
# the boundary.

⭐ WHY THIS AND NOT train_test_split
   A random split puts analogue A in train and analogue A' in
   test. The model memorises the series and reports a number
   that will not survive contact with new chemistry.

⭐ REPORT BOTH. The GAP between random and scaffold performance
   is the most informative single number in a QSAR report —
   it quantifies how much your random split was flattering you.

# --- other splits worth knowing ------------------------------
#   time split      — train on old data, test on new. The most
#                     realistic of all if you have dates.
#   cluster split   — cluster by fingerprint, split by cluster.
#   random split    — for hyperparameter tuning only, never for
#                     the headline number.
Snippet 07

Filters and structural alerts

Volume 09 · cheap triage before anything expensive
from rdkit.Chem import FilterCatalog

params = FilterCatalog.FilterCatalogParams()
params.AddCatalog(FilterCatalog.FilterCatalogParams.FilterCatalogs.PAINS)
catalog = FilterCatalog.FilterCatalog(params)

if catalog.HasMatch(mol):
    entry = catalog.GetFirstMatch(mol)
    entry.GetDescription()          # which alert fired

# other catalogs: PAINS_A / PAINS_B / PAINS_C, BRENK, NIH, ZINC

# --- Lipinski, written out -----------------------------------
def ro5_violations(mol):
    v  = int(Descriptors.MolWt(mol)    > 500)
    v += int(Crippen.MolLogP(mol)      > 5)
    v += int(rdmd.CalcNumHBD(mol)      > 5)
    v += int(rdmd.CalcNumHBA(mol)      > 10)
    return v                        # conventionally: <= 1 is fine

⭐ FLAG, DO NOT DELETE.
   PAINS is a set of SUSPICIONS derived from specific assay
   types, not a verdict — real drugs match PAINS patterns.
   Lipinski describes what has historically been orally
   available, not what binds. Both belong in a "review this"
   column, not in a WHERE clause.
Snippet 08

Conformers and 3D

Volume 12 · everything 3D depends silently on this
from rdkit.Chem import AllChem

mol = Chem.AddHs(mol)                       # ⭐ HYDROGENS FIRST.
                                            # 3D without them is wrong.

params = AllChem.ETKDGv3()
params.randomSeed = 42                      # ⭐ reproducibility
cids = AllChem.EmbedMultipleConfs(mol, numConfs=200, params=params)

res = AllChem.MMFFOptimizeMoleculeConfs(mol)    # [(converged, energy)]
# or AllChem.UFFOptimizeMoleculeConfs(mol)

energies = [e for conv, e in res]
best = cids[int(np.argmin(energies))]

Chem.MolToMolBlock(mol, confId=best)
mol = Chem.RemoveHs(mol)                    # for 2D output only

# RMSD between conformers / molecules
from rdkit.Chem import rdMolAlign
rdMolAlign.GetBestRMS(probe, ref)           # ⭐ handles symmetry;
                                            # plain AlignMol does not

HOW MANY CONFORMERS
    rigid      ~50        typical drug  200       flexible  200-500
    (roughly 3^N conformers exist for N rotatable bonds:
     N=8 -> ~6,500)

⭐ THE INVISIBLE FAILURE
   If the bioactive conformer is not in your generated set,
   docking cannot find the right pose — and nothing in the
   output will tell you. The bioactive conformer is often NOT
   the lowest-energy one.

Reference

Activity units — the conversion you will need constantly

Volume 06 · getting this wrong silently ruins a dataset
pIC50 = -log10( IC50 in MOLAR )

    IC50 = 1 nM   = 1e-9 M    ->  pIC50 = 9     very potent
    IC50 = 100 nM = 1e-7 M    ->  pIC50 = 7     good
    IC50 = 1 uM   = 1e-6 M    ->  pIC50 = 6     moderate
    IC50 = 100 uM = 1e-4 M    ->  pIC50 = 4     weak / inactive

⭐ ALWAYS MODEL THE LOG FORM. Activity spans orders of
   magnitude; a regressor on raw IC50 optimises the weak
   compounds you do not care about, because they carry the
   largest absolute errors.

⭐ AND THE ONE THAT DESTROYS DATASETS
   IC50, Ki and EC50 ARE NOT INTERCHANGEABLE.
     Ki    — a true binding constant, assay-independent
     IC50  — depends on substrate concentration and assay setup
     EC50  — a functional/cellular response, not binding
   Mixing them in one column and averaging is the classic
   fatal curation error. Model one, or model them as separate
   tasks and say which.

⭐ CENSORED VALUES ARE INFORMATION
   ">10000 nM" is not 10000. It means "we stopped looking".
   Dropping these biases your set toward actives; treating
   them as numbers biases your model. Flag them and decide
   deliberately.

Part IV

The traps

Reference

Twenty traps, in one list

If you remember nothing else from fifteen volumes, remember these
DATA
 1  MolFromSmiles returns None on failure. It does not raise.
    Check every time, and LOG the failures — never drop silently.
 2  Two SMILES for the same molecule are not equal as strings.
    Canonicalise before comparing anything.
 3  Salts and solvates make one compound look like three.
    Strip them, and record that you did.
 4  IC50, Ki and EC50 are not interchangeable. Do not average them.
 5  ">10000" is not 10000. Censored values are information.
 6  Model the log (pIC50), not the raw concentration.
 7  Never clean in place. Keep the raw column.

MODELLING
 8  A random split leaks structure through analogue series.
    Scaffold split for the headline number, and report both.
 9  Scale, impute and select features INSIDE the fold, after
    splitting. Doing it first leaks the test set.
10  Always run y-randomisation. If a shuffled model still
    performs, you have a leak, not a model.
11  An R2 of 0.92 is a reason for suspicion, not celebration.
12  A model without an applicability domain will confidently
    answer questions about chemistry it has never seen.
13  Activity cliffs cap your accuracy. Find them and report
    them rather than smoothing them away.
14  Always have a baseline. Improvement over nothing is not
    a measurement.

STRUCTURE
15  A raw PDB has no hydrogens and undecided protonation states.
16  Docking scores carry 2-3 kcal/mol error — so no affinity
    claims, and no SAR from score differences.
17  The top pose is right 50-70% of the time. Look at several.
18  Check pLDDT at the BINDING SITE, not the global average.
19  If the bioactive conformer is not in your conformer set,
    docking cannot succeed, and nothing will tell you.

GENERATION AND MODELS
20  A generated molecule is a picture until someone can make it.
    Put synthesizability INSIDE the scoring function — and never
    let a language model compute a chemical fact.
Try it · One last check — you are handed a CSV of 8,000 compounds and asked for "a model for potency by Friday". What are the first four things you do?
Answer

None of them is training a model.

1  ASK WHAT DECISION IT CHANGES.
   "A model for potency" is not a specification. Will it
   rank compounds for synthesis? Triage a purchase list?
   Support a go/no-go? The answer changes the metric, the
   threshold and whether the project is worth doing.

2  LOOK AT THE ACTIVITY COLUMN.
   One assay type, or three mixed together? Any censored
   values? Is it already logged? ⭐ This is where datasets
   are silently ruined, and it takes ten minutes.

3  COUNT SCAFFOLDS, NOT COMPOUNDS.
   8,000 compounds across 40 scaffolds is a small dataset
   wearing a large dataset's clothes — and it decides
   whether a scaffold split is even possible.

4  BUILD THE BASELINE.
   A mean predictor, or nearest-neighbour on ECFP4. Without
   it you cannot claim any model improved anything.

THEN model. And report the scaffold-split number, with an
applicability domain, or you have produced a guess with a
decimal point.

If you reached for those four before reaching for scikit-learn, the course worked.

Part V

Glossary

Glossary

A – F

ADMET
Absorption, Distribution, Metabolism, Excretion, Toxicity. The properties that decide whether an active molecule can be a drug — and the cause of most late-stage failures.
AlphaFold
DeepMind's protein structure prediction system. Predicts the apo structure; check pLDDT at your binding site before docking into one.
Applicability domain
The region of chemical space where a model's predictions are trustworthy. Outside it the model still answers, with no warning. The most important practical idea in the course.
Aromaticity
A property of certain cyclic systems. Different toolkits use different aromaticity models, so the same molecule can be perceived differently — a real source of cross-tool disagreement.
Activity cliff
Two very similar molecules with very different activity. Where similarity-based models are guaranteed to fail.
BigSMILES
An extension of SMILES for polymers, which are stochastic rather than exact structures.
Bemis–Murcko scaffold
A molecule stripped to its ring systems and linkers. The basis of scaffold splitting.
CASP
Computer-Aided Synthesis Planning — tools like AiZynthFinder that search for synthetic routes.
ChEMBL
The major public bioactivity database. Updates quarterly, so "ChEMBL" is not a version — pin the number.
Conformer
One 3D shape a molecule can adopt. Roughly 3N exist for N rotatable bonds.
Descriptor
A computed number summarising a molecule — MW, logP, TPSA. Interpretable, unlike fingerprint bits.
DFT
Density Functional Theory. The quantum method behind most materials databases — and the reason those labels are calculations, not measurements.
Docking
Predicting how a molecule sits in a binding site. A search plus a score, each fallible independently.
ECFP
Extended Connectivity Fingerprint, the Morgan fingerprint. ECFP4 means radius 2 — the 4 is the diameter.
Enrichment factor
How many times more actives you find in the top x% than by chance. The metric that matters in screening.
ETKDG
RDKit's conformer generation method, biased by torsion preferences measured from crystal structures.
FEP
Free Energy Perturbation. The accurate but expensive way to rank similar ligands. R² 0.5–0.7, hours per molecule.
Fingerprint
A bit vector encoding a molecule's substructures. The workhorse representation of the field.
Glossary

G – O

GNN
Graph Neural Network. Learns a representation from the molecular graph by message passing, rather than using a fixed fingerprint recipe.
hERG
A cardiac ion channel. Blocking it causes fatal arrhythmia, making it one of the most important toxicity endpoints to predict.
InChIKey
A 27-character hashed identifier. The standard database key for a chemical structure.
IC50
The concentration giving 50% inhibition. Assay-dependent — not interchangeable with Ki or EC50.
Lead optimisation
The phase after hit finding, where one series is refined. The point at which your model's applicability domain usually stops covering the compounds being submitted.
Ligand efficiency
Binding energy per heavy atom. Stops you rewarding molecules for simply getting bigger.
Lipinski's rule of five
MW < 500, logP < 5, HBD ≤ 5, HBA ≤ 10. A description of orally available drugs, not a law and not a filter.
logP
Partition coefficient — greasiness. RDKit's MolLogP is calculated and routinely differs from measured logP by 0.5–1 unit.
MACCS keys
A fixed 166-bit fingerprint of predefined substructures. Fast, interpretable, coarse.
Matched molecular pair
Two molecules differing by one defined transformation. The right way to talk about SAR with a chemist.
MD
Molecular Dynamics. Simulates motion over time. Good for pose stability, not for affinity.
Mode collapse
A generative model converging on a narrow set of outputs. Spotted by uniqueness falling while reward rises.
MMFF94 / UFF
Force fields used to optimise conformer geometries in RDKit.
OECD principles
The five validation requirements that make a QSAR model regulatory-defensible — including a defined endpoint, an applicability domain and mechanistic interpretation where possible.
Glossary

P – Z

PAINS
Pan-Assay Interference Compounds — substructures that produce false positives in many assays. A flag prompting review, not a delete.
PDB
The Protein Data Bank, and its file format. Around 220,000 experimental structures. Contains no hydrogens.
pIC50
−log10(IC50 in molar). Always model this rather than raw concentration.
pLDDT
AlphaFold's per-residue confidence, 0–100, stored in the B-factor column. Read it at the binding site, not globally.
Pharmacophore
The abstract 3D pattern of features required for binding. The method that finds scaffold hops.
QSAR
Quantitative Structure–Activity Relationship. A model mapping structure to activity — the field's central technique.
RDKit
The open-source cheminformatics toolkit this entire course is built on. Pin its version: descriptor and aromaticity behaviour changes between releases.
REINVENT
The industry-standard generative model. A frozen prior, a learning agent, a scoring function, and σ as the leash between them.
Retrosynthesis
Planning a synthesis backwards from the target. Template-based uses reaction rules; template-free treats it as translation.
SA Score
Synthetic Accessibility, 1 (easy) to 10 (hard). Heuristic, based on fragment frequency in PubChem.
Scaffold split
Splitting data so that whole scaffolds stay on one side. The honest way to estimate performance on new chemistry.
SCScore
Synthetic Complexity, 1 (simple) to 5 (complex). Learned from reaction data. Disagrees with SA Score by design.
SMARTS
A pattern language for substructure queries. Related to SMILES, but it matches many molecules rather than describing one.
SMILES
A text representation of a molecule. Non-unique without canonicalisation, and carries no 3D information.
Tanimoto
The standard fingerprint similarity coefficient. Its value is meaningless without naming the fingerprint that produced it.
Tautomer
Structures differing by the position of a hydrogen and a double bond. The reason "are these the same compound?" is genuinely hard.
TPSA
Topological Polar Surface Area. Below ~90 Å² is the usual rule of thumb for brain penetration; below 140 for oral absorption.
USPTO
Reactions text-mined from US patents. Flawed — parsing errors, poor atom mapping, unreliable yields — and universal, because there is no free alternative.
Virtual screening
Computationally ranking a library to choose what to test. Judged by enrichment, not by accuracy.
Y-randomisation
Shuffle the labels and retrain. If performance survives, you have a leak. Run it every time.

One per volume
01  A molecule is a physical object and a computer cannot hold
    one — everything in this field follows from that.
02  The toolchain is RDKit plus the scientific Python stack, and
    knowing it deeply beats knowing ten tools shallowly.

    and each one loses something different.

    sanitisation and canonicalisation behaviour, not just its API.
05  A fingerprint is a fixed recipe for describing structure, and
    a descriptor is a number you can explain to a chemist.
06  Curation is most of the work, and the audit trail is the
    deliverable a senior scientist actually reads.
07  Chemical space is too big to see, so you cluster, project and
    sample it — and every projection lies somewhere.

Where to go for the real thing

The documentation

The RDKit Book and its Getting Started guide are unusually good, and closer to the source of truth than any summary — including this one.

The source knowledge base

docs/ai-cheminformatics-knowledge-base/ — 57 markdown files, roughly 77,700 lines, with the full code, the worked solutions and the exercise briefs these volumes summarise.

The journals

J. Chem. Inf. Model., J. Cheminformatics (open access), and ChemRxiv for preprints — where methods appear about a year before the journals.

The community

The RDKit UGM is unusually practical, and the RDKit mailing list and GitHub discussions are where the maintainers answer questions directly.

On what will age. Library APIs move — the fingerprint generator interface in Snippet 04 replaced an older call that still appears everywhere, and something will replace it in turn. Model names and benchmark numbers will date faster still. What will not age is the reasoning: that a split decides whether a number is honest, that a prediction without an applicability domain is a guess with a decimal point, and that a generated molecule is a picture until someone can make it.
