How to use this folder

Every volume is a single self-contained HTML file — no build step, no dependencies beyond Google Fonts, and all the cross-links are relative. That means:

  • Open index.html in a browser and everything works, straight off disk.
  • Push the folder to GitHub and enable Pages on it — the links resolve unchanged.
  • Each volume has a sticky contents rail that highlights the section you are reading, a strip of tabs to the other fourteen, and respects your system light/dark preference.
How the teaching works

Two devices repeat throughout. Worked examples take one concrete thing — the Morgan algorithm on ethanol, a SMILES model writing CCO character by character, three temperatures on the same sampling step, 0.96 against 0.53 — and walk it slowly, because the concepts in this field are much easier to see on one small molecule than to read about. And the four-band blocks state what a thing is, how it works, what juniors get wrong, and the question you should be able to answer about it.

Where this comes from. These 17 volumes are the taught, navigable edition of 57 markdown files — roughly 77,700 lines — in docs/ai-cheminformatics-knowledge-base/: five phase folders, nine exercise briefs with full worked solutions, and seven field-insight files. The originals hold the complete code, the full exercise briefs and the capstone specifications; these carry the concepts, the mechanisms and the judgement.

On what will age. Library APIs move, model names date, and benchmark numbers drift. The reasoning will not: that a split decides whether a number is honest, that a prediction without an applicability domain is a guess with a decimal point, and that a generated molecule is a picture until someone can make it.
